## ⚡ Highlights

- **Interactive Bento Grid**: Draggable, physics-based modular layout with snap-back reset.
- **Palm-Leaf Manuscript (பனை ஓலைச்சுவடி)**: Minimal 3D bundle with Thirukkural couplets on craft and empathy, finished with a warm dedication.
- **Editorial Header (`அன்புடன் 📜`)**: Direct interactive trigger to open the palm-leaf manuscript.
- **Live Production Showcase**: Production iOS and Android applications with live App Store and Play Store links.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Motion (Framer Motion v12)
- **Icons**: Lucide React
- **CI/CD**: GitHub Actions ➔ GitHub Pages

---

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/kaushalboii/Kaushals-portfolio-mini.git
cd Kaushals-portfolio-mini

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```
