## ✨ Features & Japanese Aesthetic Design System

- **和紙 (Washi) & 墨 (Sumi) Palette**: Deep warm ink neutrals (`#131110`, `#1a1715`) paired with warm paper whites (`#f0eade`), vermilion accents (`#e1532e` 朱), and subtle gold highlights (`#d9b35c` 金).
- **Interactive Bento Grid**: Draggable cards powered by Motion with smart click-vs-drag detection, boundary constraints, and instant "tidy up" re-alignment.
- **Eye-Tracking Mascot (`PortfolioEyes`)**: Real-time batch-rendered gaze tracking following the user's cursor.
- **24K Gold Ability Card (黄金札)**: Interactive 3D holographic ability card with gyroscopic mouse/touch tilt, dynamic specular sheen, rainbow diffraction foil, and 180° flip to the embossed monogram reverse.
- **Verified Mobile & Web Production Suite**:
  - 🍏 **ZenLife: Stress & Sound Relief** (Apple App Store) — 432 Hz Solfeggio acoustic synthesizer with CoreData persistence.
  - 📡 **Viana 360** (Apple App Store) — Real-time telemetry & IoT multi-sensor dashboard.
  - 🛍️ **Viana Buy** (Apple App Store) — Lifestyle quick-commerce with local cart persistence.
  - ⌨️ **CleanYourMac Keyboard** (macOS Universal) — Low-level CGEventTap keyboard lockout utility.
  - 🤖 **Vellore Ads Platform** (Google Play Store) — Jetpack Compose commercial classifieds directory.
  - 📜 **Constitution of India (REF)** (Google Play Store) — Offline SQLite FTS5 bilingual bare act reference.
  - ⚖️ **BNS & BNSS 2023 Statutory Suite** (Google Play Store) — Criminal law reform cross-matrix.
  - 💻 **CodeShift Collaborative Editor** (Web) — Monaco Engine with client-side AES-GCM encryption.
  - 🛰️ **India News Radar** (Web) — Geotagged interactive SVG intelligence map.
- **Live GitHub Star Sync**: Serverless edge-cached star counter for open-source repositories.
- **Responsive Architecture**: Fluid layout scaling from 320px mobile screens to 4K displays.

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Start local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
